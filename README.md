## Projeto 3D printer app

Situação problema:
Este projeto consiste no desenvolvimento de uma API backend para um sistema empresarial. Cujo busca possuir um meio de persistir os dados de seus clientes, orçamentos, materiais, serviços, colaboradores e outras informações relevantes. De forma a manter a segurança de seus dados através de uma API com contratos para disponibilização de recursos, forte validação de dados provenientes das requisições http, autenticação e autorização de recurso.
